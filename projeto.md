Apresentação do Projeto Front-end
Bem-vindos(as) ao projeto final de Front-end! Esta é a oportunidade de aplicar tudo o que aprendemos, utilizando tecnologias modernas e boas práticas. O projeto terá como base a documentação do Digital Store e o design visual disponível no Figma.

Objetivo:
Desenvolver uma aplicação web completa utilizando React. Vocês deverão implementar funcionalidades essenciais, seguindo os requisitos mínimos da documentação.

Estrutura do Projeto
Requisitos Mínimos: Obrigatórios (descritos na documentação oficial).
Páginas Principais:
Página Inicial (Home)
Página de Listagem de Produtos
Página de Visualização do Produto
Tecnologia: React (pode usar TypeScript). Bibliotecas de estilo são permitidas (MaterialUI, PrimeReact, Bootstrap, Tailwind, etc.).
Entrega e Avaliação
Data Final: 20/11/2026

Valor: De 0 a 10 (equivale a 50% da nota do curso).

Formato: Link do repositório no GitHub.

Equipes e Suporte
Trabalho em Equipe: Permitido até 3 pessoas (3 pessoas contando com você, e sim, pode ser feito sozinho(a) ou em 2 pessoas). (Obrigatório informar o nome de todos na entrega).
Monitoria: Às segundas, das 18h30 às 22h30 e de terça a sexta-feira, das 19h30 às 21h30.
Critérios de Avaliação
Construção Lógica
Aplicação correta do React
Conformidade com os Requisitos Mínimos
Estilo e Design (Fidelidade ao Figma)
Documentação e Entrega
Boas Práticas de Código
